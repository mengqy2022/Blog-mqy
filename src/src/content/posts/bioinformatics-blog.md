## Introduction

Before setting up this new blog, I maintained a bioinformatics blog on GitHub Pages using **Jekyll (Minimal Mistakes theme)**:

**"Give Me Some Passion!"** — https://mengqy2022.github.io/

It records practical notes I accumulated while learning bioinformatics analysis, covering comparative genomics, functional annotation, phylogenetics and many other topics.

## What's inside

- **Comparative genomics**
- **KEGG annotation** (kegg-ann / kegg-modules / kegg-infomation)
- **GO functional annotation** (GO / eggNOG-mapper)
- **Phylogenetic analysis** (phylogenetic / tree-heatmap)
- **Genome & gene prediction** (genome-prediction / ciliate-prediction / telomere)
- **Data visualization** (Upset plot / Venn plot / barplot)
- **Practical tips** (GenBank batch download, code optimization, etc.)
